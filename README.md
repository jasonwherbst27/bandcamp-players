# Bandcamp Players

Self-contained HTML music players streaming directly from Bandcamp, hosted on GitHub Pages.

## Included Players

- **Slushwave Megalith** (`slushwave-megalith.html`) — 424-release Bandcamp player with a hazy cover-art collage backdrop and Cover Wall.
- **The Heavy Underground ’25** (`doom-charts-2025.html`) — 50-track Doom Charts archive in a Googie retro-modern hi-fi player.

## Adding a New Player Later

1. In this GitHub repository, click **Add file → Upload files** and upload your new `.html` file (for example, `ambient-mix.html`).
2. Open `index.html`, click the pencil icon (**Edit this file**), and add a new entry to the `PLAYERS` list near the bottom of the file.
3. Click **Commit changes** — GitHub Pages updates automatically within about a minute.
